# 📡 crypto-bot

[English](README.md) · **العربية**

بوت إشارات بيرتّب **18 عملة كبيرة**: BTC، ETH، BNB، SOL، XRP، ADA، DOGE، TRX، LINK، AVAX، DOT، LTC، BCH، ATOM، ETC، XLM، UNI، NEAR. بيشتغل على استراتيجية **التناوب بين العملات (الزخم)**، وبينشر الإشارة على صفحة ويب مرة باليوم، بعد ما تسكّر الشمعة اليومية.

📊 **الإشارة الحية:** https://walidplayx-debug.github.io/crypto-bot/ · وفي ملخص بـ[`RESULTS.md`](RESULTS.md)

## الاستراتيجية

كل كم يوم، البوت بيرتّب العملات حسب قديش طلعت آخر N يوم:

- **بيشتري الأقوى**، بس إذا زخمها إيجابي.
- **بيبيع (Short) الأضعف**، بس إذا زخمها سلبي.
- بيضل بالصفقة للمراجعة الجاية، بدون رافعة وبدون وقف خسارة.

الفكرة: العملة اللي عم تطلع بتكمّل طلوع فترة، واللي عم تنزل بتكمّل نزول. هاد اسمه الزخم.

الإعدادات انختارت من 540 تركيبة، بالاعتماد **بس على بيانات التدريب (لحد 2023-01-01) والتحقق (لحد 2024-07-01)**. الاختبار المخفي اللي بعدها ما انستخدم بأي قرار. ويوم ما بلّش الاختبار الحي، **انثبتت** الإعدادات بـ[`docs/live.json`](docs/live.json)، والنتيجة الحية بتنحسب بس على الأيام اللي بعد هاليوم. يعني اختبار حقيقي على الورق.

## بدون غش

- المراكز بتنقرر على **إغلاق** اليوم، وبتبلّش من **افتتاح** اليوم اللي بعده.
- كل تغيير بالمراكز عليه رسوم 0.05% وانزلاق 0.03%، وفي رسوم تمويل على كل ساعة الصفقة مفتوحة فيها.
- جربنا الاستراتيجية على أسعار عشوائية بالكامل وما لقت أي ربح، يعني ما بتشوف المستقبل.

## كيف بيشتغل

GitHub Actions ([`.github/workflows/evolve.yml`](.github/workflows/evolve.yml)) بيشتغل مرة باليوم بعد إغلاق الشمعة اليومية (00:00 UTC): بينزّل الشموع اليومية الجديدة من Binance (مجاناً وبدون مفتاح API)، وبيحسب الإشارة، وبيحدّث الصفحة. ولأن الجدولة تبع GitHub كتير بتتأخر، في كذا موعد احتياطي بنفس اليوم، والتشغيلة بتتخطّى حالها إذا إشارة اليوم انحسبت.

قائمة العملات موجودة بـ[`bot/config.py`](bot/config.py) (`ROTATION_SYMBOLS`)، وأي تغيير فيها بيبلّش اختبار حي جديد. ملاحظة: القائمة فيها العملات الكبيرة *اليوم*، فالباكتست فيه شوية تحيّز للعملات اللي نجت (العملات اللي ماتت مش موجودة). الاختبار الحي ما فيه هالمشكلة.

```bash
pip install -r requirements.txt
python -m bot.fetch     # تنزيل وتحديث الشموع اليومية
python -m bot.signals   # حساب الإشارة، وكتابة docs و RESULTS.md
```

## تاريخ البحث

قبل التناوب، **خوارزمية جينية** دوّرت على استراتيجيات مبنية على شروط مؤشرات: 26 مؤشر، و3 فريمات، وأوامر ليمت، وتقييم على أسوأ سنتين، و3 بحوث مستقلة لكل استراتيجية، وتحليل خسائر. بعد حوالي 80 تشغيلة ما لقت شي بيصمد على الاختبار المخفي، فوقّفناها. الكود تبعها محفوظ بمجلد [`research/`](research/). بتشغّله بـ`python -m bot.fetch --hourly` وبعدين `python -m research.evolve` و`python -m research.report`، بس انتبه إن التقرير بيكتب فوق `docs/data.json`.
